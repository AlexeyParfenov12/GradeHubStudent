# GradeHub

Веб-система для работы с учебными группами, студентами, курсами, занятиями, тестами, посещаемостью и задолженностями.

## Что есть в проекте

- управление курсами и группами;
- добавление и редактирование студентов;
- работа с занятиями и тестами;
- учёт посещаемости;
- работа с задолженностями и итоговой аттестацией;
- AJAX-запросы для отдельных операций;
- PHP-контроллеры и работа с MySQL.

## Технологии

PHP, MySQL, JavaScript, AJAX, HTML, CSS

## Настройка подключения к базе данных

Данные подключения не хранятся в репозитории. Перед запуском нужно задать переменные окружения:

```text
DB_HOST=localhost
DB_USER=имя_пользователя
DB_PASSWORD=пароль
DB_NAME=имя_базы
```

Файл `function/connect.php` получает эти значения через `getenv()` и создаёт обычное подключение `mysqli`.

## Статус

Рабочий учебный/fullstack-проект, который продолжает дорабатываться. В портфолио используется как пример более крупного проекта на PHP и MySQL.
